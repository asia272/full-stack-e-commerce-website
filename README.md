# 🛍️ Full-Stack E-Commerce Website

A modern full-stack e-commerce web application built with **Next.js, TypeScript, Prisma, PostgreSQL, Neon, Better Auth, Stripe, Cloudinary, and Tailwind CSS**.

This project provides a complete e-commerce experience where customers can browse and search products, add products to their cart, manage cart items, provide delivery information, place orders, pay using Stripe or Cash on Delivery, view their orders, and track order progress.

The application also includes an **Admin Dashboard** where administrators can manage products, view customer orders, and update order delivery statuses.

---

## 🚀 Features

### 👤 Authentication

Authentication is implemented using **Better Auth**.

Users can:

- Register an account
- Login to their account
- Access authenticated pages
- View their own orders
- Manage their shopping cart
- Place orders

The application also supports role-based access control.
